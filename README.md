# Beach Mission – English Vocabulary

Quiz didattico interattivo sulle Activities at the Beach, ideato e realizzato dal Prof. Marco Cigolotti.

Contiene 20 immagini locali senza la scritta dell'azione, tre modalità di esercizio e una Mixed Mission. Pronuncia inglese tramite sintesi vocale del dispositivo. Compatibile con PC, tablet e smartphone.

Per GitHub Pages caricare `index.html`, `README.md` e la cartella `images` nella root del repository.
